# Was an Canva gesendet wurde

Canva-Entwurf `DAHbQg1-t6o` (drei Seiten). Gebaut wurde zuerst in der Arbeitsdatei `DAHbQVa6brM` (Seiten 7 bis 9),
dann wurden diese drei Seiten in den Entwurf kopiert. Die Kennungen der Elemente blieben beim Kopieren gleich, die
der Seiten änderten sich.

| Datei | Inhalt |
|---|---|
| `seiten.json` | Seitenkennungen in der Arbeitsdatei |
| `medien.json` | Kennungen der hochgeladenen Grafiken und der Aufnahme |
| `folie-N-einfuegen.json` | erster Aufbau je Folie: Formen, Bilder, Texte, Notizen |
| `folie-N-texte.json`, `folie-N-format.json` | Schriftformate; `folie-N-kennungen.json` ordnet jedem Text seine Kennung zu |
| `kennungen-entwurf.json` | Kennungen im Entwurf `DAHbQg1-t6o` für die Korrekturen |
| `folie-2-korrektur.json`, `folie-3-korrektur.json` | Korrekturen im Entwurf: Legende der Datenfolie; größere Beschriftungen am Zeitstrahl; Aufnahme als SVG-Hülle |
| `stand-final.json` | Endstand aller Elemente; daran laufen die Prüfungen |

Zwei Befehle wurden von Hand ergänzt und stehen in keiner Datei: der Bildausschnitt der Aufnahme auf Folie 3
(`crop_media` auf 1367 × 720 ab der linken oberen Ecke, weil Canva das getauschte Bild zunächst um etwa 3 % vergrößert
hatte) und die Farbe des Fragezeichens auf Folie 2 (`#96590A`). Der Titel des Entwurfs wurde mit `update_title` gesetzt.

Die Arbeitsdatei enthält außerdem Probeseiten und Probebilder. Sie kann gelöscht werden.
